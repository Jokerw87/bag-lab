# 小袋子实验室 / Bag Lab

## V1.1 共用纵轴

默认两图共用同一概率上限，取两组理论概率与模拟频率的最大值（至少0.01）；同样柱高代表同样概率。取消勾选可恢复各自缩放。此选择只重新绘图，不重新模拟，不改变表格或 CSV。导出PNG含当前刻度方式说明。不是新增统计方法。

离线比较放回与不放回抽样。原创教学小工具，不是随机抽奖或预测系统。

## 三步使用

1. 下载全部源文件到同一目录，用现代桌面浏览器打开 `index.html`。
2. 设置两色球数、每轮抽取数、轮数和种子，点击运行。
3. 查看概率图和表格，再保存 PNG 或数值 CSV。修改参数会清空旧结果并禁止旧结果导出。

默认 3 个橙球、2 个蓝球、每轮抽 2 个，是虚构演示。每轮重新装满袋子；不放回仅在同一轮内适用。

## 解释与限制

放回对应二项分布，不放回对应超几何分布。表格百分数保留两位小数，显示 0.00% 不一定代表数学上的零，CSV 提供更多有效数字。图下标明各自上限；默认共用刻度，独立缩放时不能直接比较跨图柱高，精确概率请核对表格。

两模式采用独立确定性伪随机流；相同设置可复现，不是逐次配对比较，也不是密码学随机性。浮点运算存在舍入误差。模拟次数增加不保证某一次误差单调减小。

总数 1–100，每色 0–50，每轮 1–30 且不超过总数，轮数 1–10000，种子 0–4294967295。无上传、账号、持久存储、网络 API 或字体下载。刷新即清除结果；先下载需要的文件。
